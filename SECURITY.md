# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through the "Report a vulnerability" form in the repository's Security tab, at `https://github.com/lucawalz/strata/security/advisories/new`. Do not open a public issue, pull request or discussion for a suspected vulnerability.

A useful report names the affected version or commit, describes the impact, and includes steps or a proof of concept that reproduce the problem.

## Response

- Acknowledgement within 7 days of the report.
- Coordinated disclosure within 90 days of the report, earlier when a fix ships sooner.
- The reporter is credited in the published advisory unless they ask otherwise.

## Supported versions

Only the latest release, or the default branch for repositories without releases, receives security fixes.
